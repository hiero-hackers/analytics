# Code of Conduct

Please review the Linux Foundation Decentralized Trust
[Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct) before
participating. As a Hiero ecosystem project, `hiero-hackers/analytics` follows the
same standard as the wider [Hiero community](https://github.com/hiero-ledger/.github/blob/main/CODE_OF_CONDUCT.md).

It is important that we keep things civil and welcoming. This applies to all
project spaces — issues, pull requests, discussions, and any Hiero community
channel where this project is discussed.

## Reporting

If you experience or witness unacceptable behaviour, please report it to the
project maintainers (see [MAINTAINERS.md](MAINTAINERS.md)) or, for matters that
should be escalated beyond this project, to the LF Decentralized Trust per the
[Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct) linked above.
