# Maintainers

This file lists the maintainers of `hiero-hackers/analytics`. Maintainers review
and merge pull requests, triage issues, and are responsible for the health and
direction of the project.

`hiero-hackers/analytics` is a community project in the
[Hiero Hackers](https://github.com/hiero-hackers) organisation. It follows the
spirit of the [Hiero maintainer guidelines](https://github.com/hiero-ledger/.github/blob/main/CONTRIBUTING.md#about-users-and-maintainers),
adapted to a smaller community tool.

## Becoming a maintainer

Sustained, high-quality contribution is the path to maintainership. Contributors
who consistently deliver reviewed work, help others, and demonstrate good judgment
may be nominated by an existing maintainer and added via a pull request to this
file.

## The duties of a maintainer

- Review pull requests promptly and fairly, holding them to the standards in
  [CONTRIBUTING.md](CONTRIBUTING.md).
- Triage and label incoming issues.
- Uphold the [Code of Conduct](CODE_OF_CONDUCT.md) in all project spaces.
- Follow the [Security Policy](SECURITY.md) for any privately reported vulnerability.
